# Programación 1 - Dedicada a Objetos

Este proyecto contiene ejercicios y actividades de programación orientada a objetos en Python.

## Estructura

- `Ac.metodos/`: ejercicios sobre métodos y clases.
- `inicio/`: práctica inicial con variables, condicionales, bucles y ejercicios de clase.
- `repaso/`: actividades de repaso.
- `Tarea2/`: tareas y ejercicios entregables.

## Requisitos

- Python 3.x

## Cómo ejecutar un archivo

```bash
python "ruta/al/archivo.py"
```

Ejemplo:

```bash
python "repaso/Repaso1y2/repaso2.py"
```
